# Manual illustration guidance

- Manual-only illustrations explain machine selection and Portable/Desktop
  operation. They are documentation assets, not Resource Pack texture sources.
- Keep each image claim synchronized with current machine names, hardware,
  built-in display requirements, and user procedures. Do not depict unsupported
  controls, ports, networking, media insertion, or terminal capability.
- Preserve intrinsic dimensions, useful alt text, bounded file size, supported
  PNG format, and responsive layout. Do not include UI secrets, connection
  numbers, player/world data, or workstation-specific content.
- Verify the live manual and static no-JS/manual presentation in desktop and
  narrow mobile browsers.
