# CPU plate guidance

- This directory contains authored CS386SX, CS486DX, and CS486DX2 identification
  plates. Filenames and labels are part of the manual/public asset contract.
- Keep model spelling, clock/profile claims, cache/bus descriptions, and visual
  family synchronized with domain timing/cache rules, CSBIOS, `run --stats`, and
  Manual Chapter 09 (`architecture`).
- Do not add a CPU plate for an unimplemented hardware profile or imply native
  x86 execution. These plates describe the deterministic guest model.
- Preserve supported PNG format, dimensions/transparency intent, intrinsic
  markup dimensions, alt text, and static Pages copying. Verify desktop/mobile
  manual layout and no horizontal overflow.
