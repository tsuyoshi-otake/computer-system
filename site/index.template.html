Publication 03 · Program cycle

Write. Compile. Measure. Connect.

The toolchain and every program stay inside the guest sandbox. Modeled cycles—not browser wall time—describe guest execution cost.

  1. 01

    Write

    vi /startup.py

    Edit in the fixed 80×25 terminal.

  2. 02

    Compile

    cc -c /fastmath.c -o /fastmath.o

    Build validated CS486 objects and executables.

  3. 03

    Measure

    run --stats /program

    Inspect instructions, cycles, cache, and bus activity.

  4. 04

    Connect

    i2c 0 scan

    Use Redstone and bounded face-local peripherals.

Publication 04 · Honest boundaries

A sandbox is useful when its limits are explicit.

No host escape

Guest commands never launch PowerShell, cmd.exe, BDS administration, native binaries, or a host compiler.

No fictional network

Guest IP networking, routes, DNS, package management, ping, and ss are not implemented yet.

Floppy media is absent

The modeled FDD reports no media until a future Bedrock insertion adapter owns that state.

Web Terminal is local

This Pages site publishes documentation only. Live machine access still requires the local BDS Web companion and an activated code from Minecraft.
