# Computer System v0.1.0-alpha.1

This is the first public alpha preview of Computer System. It publishes the
implemented Phase 2 vertical slice for evaluation while the broader Phase 6
release-hardening work remains open in Issue #8.

## Highlights

- Persistent CS486DX and CS486DX2 desktops running CS-Linux 1.0.
- Portable CS386SX machines running CS-DOS 6.2.
- Computer System Python on desktop CS-Linux; ASM, C, and C++ on both profiles.
- DOS-only CS QBASIC with the shared full-screen EDIT engine and bounded mouse
  input.
- Redstone and local peripheral modeling, persistent guest storage, and the
  local authenticated Web Terminal companion.
- A public 16-chapter field manual at
  <https://tsuyoshi-otake.github.io/computer-system/>.

## Install

1. Back up the stopped target world.
2. Download and open `computer-system-0.1.0-alpha.1.mcaddon`.
3. Activate the imported Computer System Behavior Pack in the world settings;
   its dependency activates the matching Resource Pack.
4. Use Minecraft Bedrock Edition 1.26.30 or later in the 1.26 release line.

Separate Behavior and Resource `.mcpack` files and `SHA256SUMS.txt` are provided
for operators who need to verify or import each pack independently. The release
archives omit repository guidance and JavaScript source maps.

## Alpha boundaries

- This is a prerelease, not the Phase 6 hardened release. Back up worlds before
  testing and do not treat it as long-duration multiplayer acceptance.
- GitHub Pages is documentation only. Live terminal access requires the local
  Web companion from the source repository.
- Guest IP networking, routes, DNS, package management, `ping`, and `ss` are not
  implemented. Floppy media insertion is also not connected to Bedrock yet.
- CS-Linux deliberately has no BASIC command. CS QBASIC is available only on
  CS-DOS.
