# Computer System v0.1.0-alpha.5

This fifth public alpha is a focused lifecycle-fidelity update for the live Web
Terminal. It makes the CRT follow the authoritative Computer Display power state
while retaining the terminal cells for the next powered frame.

This remains a prerelease. Back up a stopped world before testing it; persisted
data compatibility is not guaranteed between development alphas.

## Highlights

- Propagated the authoritative Bedrock Display state in shared Web Terminal
  snapshot frames and cache identity.
- Made the CRT optical layer go dark when the Display or lifecycle reaches
  `off`, without clearing the retained terminal buffer.
- Disabled Copy while the Display is off and restored it with the next powered
  frame.
- Added a fail-dark initial state and a lifecycle fallback for mixed companion
  and Behavior Pack versions.
- Added focused Web UI, display-power, bridge-contract, and canonical-manual
  regression coverage.

## Install

1. Back up the stopped target world.
2. Download and open `computer-system-0.1.0-alpha.5.mcaddon`.
3. Activate the imported Computer System Behavior Pack; its dependency activates
   the matching Resource Pack.
4. Use Minecraft Bedrock Edition 1.26.30 or later in the 1.26 release line.

The release ships Resource Pack 0.1.16 and Behavior Pack 0.1.8. Separate
Behavior and Resource `.mcpack` files and `SHA256SUMS.txt` are provided for
independent verification and import.

Live Web Terminal features require the source release and the local companion;
GitHub Pages remains documentation only.

## Alpha boundaries

- This is not the Phase 6 hardened release and is not long-duration multiplayer
  acceptance.
- Persisted world/data compatibility is not guaranteed between development
  alphas.
- Guest networking, package management, dynamic loading, unrestricted
  processes/threads/sockets, and CS Windows remain future work.
- The preserved reduced NetHack prototype remains frozen and is not release
  completion evidence.
