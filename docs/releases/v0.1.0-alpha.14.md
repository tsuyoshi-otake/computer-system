# Computer System v0.1.0-alpha.14

This fourteenth public alpha is an integrated guest-runtime and
terminal-fidelity release. It adds persistent interactive Python, completes bare
Perl standard-input behavior, preserves submitted Web Terminal lines until the
guest display takes ownership, and ships the two narrowly reauthorized NetHack
correctness slices.

This remains a prerelease. Back up a stopped world before testing it; persisted
data compatibility is not guaranteed between development alphas.

## Highlights

### Authoritative Linux and DOS line handoff

- The Web Terminal retains one bounded, non-secret submitted line at its
  original prompt position until the exact authoritative guest cells echo it or
  a real clear, scroll, resize, restore, or changed full-screen frame replaces
  it (Issue #123).
- Linux `clear`, DOS `CLS`, NetHack, and DOS `EDIT` now transfer presentation
  ownership atomically instead of exposing an empty intermediate prompt.
- Duplicate submission, history navigation, and completion stay disabled while
  the handoff is pending. Writer loss, replacement, range loss, closure,
  protocol failure, and reconnect all finalize without replay.
- Passwords and other secret lines never enter the retained controller and leave
  the browser field before admission begins, including rejected input.

### One persistent Python 3.14 CS Profile REPL

- Bare `python` and `micropython` on supported CS-Linux desktops open a bounded
  `>>>` / `...` REPL with persistent globals, imports, functions, closures,
  classes, and generators (Issue #122).
- The complete session retains one foreground PID, scheduler entry, RAM grant,
  runtime, and production `Cs486Process`; cells are compiled and installed at a
  quiescent boundary without replaying historic source or adding another VM.
- Compound suites, incomplete delimiters and strings, final-expression display,
  syntax/runtime faults, Ctrl+C, Ctrl+D, disconnect, shutdown, reboot, and every
  capacity boundary have explicit terminal and resource-finalization outcomes.
- Interactive mode rejects redirects, pipelines, background work, scripts,
  `--stats`, MCP non-TUI execution, and filesystem extension imports before side
  effects. Existing file execution and statistics behavior remains available.

### Bare Perl source input

- `perl` with no `-e` program or script path now reads bounded program source
  from standard input (Issue #119). Pipe and redirect input compile at EOF; an
  attached terminal collects up to 64 KiB / 4,096 lines until Ctrl+D.
- Ctrl+C discards terminal source with status 130. Disconnect, logout, shutdown,
  elevation loss, malformed EOF, stale generation, and viewer input all
  terminate through one explicit owner without history or retained-source
  leakage.
- Consumed source is never replayed as runtime stdin, so programs that need data
  should continue to use `perl -e` or a script path.

### Narrowly reauthorized NetHack fidelity

- Movement now uses bounded integer eight-octant shadowcasting with separate old
  and new visibility sets, exact dirty-cell ownership, and differential terminal
  presentation. Corridor transitions no longer fall into the former full-frame
  repaint path (Issue #64).
- The fixed 16-slot inventory exposes stable `a` through `p` selections and
  distinct eat, quaff, read, wield, wear, take-off, drop, and pickup flows.
  Equipment and bounded ground stacks survive exact version-3 saves; validated
  version-2 saves remain readable and migrate on the next explicit save.
- These are the two user-authorized maintenance slices only. The wider reduced
  game remains frozen and excluded from completion percentages.

## Bounds and compatibility

- Terminal snapshots carry validated monotonic terminal revision and replacement
  counters. The replacement counter is transient, is absent from persisted
  Computer snapshots, and does not advance for ordinary writes or unchanged
  full-frame application.
- The browser stores at most one 128-character submitted line and validates at
  most a 200 by 100 terminal grid. Perl and Python retain their documented
  source, work, output, heap, code, and session ceilings.
- The single production CS486 implementation and guest/host security boundary
  are unchanged. Guest input is never dispatched to PowerShell, `cmd.exe`, Node
  child processes, arbitrary BDS administration commands, or host compilers.
- This is not the Phase 6 release-hardening milestone, long-duration multiplayer
  acceptance, or a claim of upstream Perl, Python, POSIX, or NetHack
  conformance.

## Packaging

The Behavior Pack moves to 0.1.18 because the generated runtime script changed.
The Resource Pack stays at 0.1.18 because no shipped artwork, localization,
geometry, texture, or JSON UI changed. The combined add-on declares the matching
0.1.18 Resource Pack dependency.

The `.mcaddon` ships the guest runtime and NetHack changes. Live Web Terminal
handoff and interactive browser behavior require the local companion from this
tag; GitHub Pages remains a static manual rather than a terminal endpoint.
