# Computer System v0.1.0-alpha.6

This sixth public alpha strengthens the live Web Terminal input boundary. It
makes Ctrl+C ownership explicit across the browser, companion, Bedrock bridge,
and guest runtime, and moves ambiguous shell-completion presentation back into
the authoritative terminal.

This remains a prerelease. Back up a stopped world before testing it; persisted
data compatibility is not guaranteed between development alphas.

## Highlights

- Added a versioned Ctrl+C action contract for shell line aborts, authentication
  cancellation, runtime interrupts, guest TUI keys, and unavailable sessions.
- Added interaction-generation fencing so stale keys, completion requests,
  pointer input, and Ctrl+C requests cannot mutate a replacement interaction.
- Prevented an idle Ctrl+C request from falling through to stopping the
  Computer.
- Preserved Meta+C as browser copy and made interruptible foreground ownership
  take precedence over incidental DOM selection.
- Moved ambiguous command and path completion lists into the fixed-cell guest
  terminal, with bounded columns, truncation, and authoritative prompt redraw.
- Added explicit first-boot password cancellation and closed-pager ownership
  finalization.
- Rescaled and centered the Floppy Disk item artwork and advanced both pack
  versions to invalidate cached Resource Pack UI and textures.

## Install

1. Back up the stopped target world.
2. Download and open `computer-system-0.1.0-alpha.6.mcaddon`.
3. Activate the imported Computer System Behavior Pack; its dependency activates
   the matching Resource Pack.
4. Use Minecraft Bedrock Edition 1.26.30 or later in the 1.26 release line.

The release ships Resource Pack 0.1.17 and Behavior Pack 0.1.9. Separate
Behavior and Resource `.mcpack` files and `SHA256SUMS.txt` are provided for
independent verification and import.

Live Web Terminal features require the source release and the local companion;
GitHub Pages remains documentation only.

## Alpha boundaries

- Issue #105 remains open for the command-specific pager, CS ASM WorkBench, and
  foreground-job interruption matrix beyond this protocol foundation.
- This is not the Phase 6 hardened release and is not long-duration multiplayer
  acceptance.
- Persisted world/data compatibility is not guaranteed between development
  alphas.
- Guest networking, package management, dynamic loading, unrestricted
  processes/threads/sockets, and CS Windows remain future work.
- The preserved reduced NetHack prototype remains frozen and is not release
  completion evidence.

## Verification

- Focused terminal, runtime, authentication, companion, browser-input, and
  Bedrock bridge suites passed with 170 tests.
- `npm run validate` passed formatting, ESLint, TypeScript, 285 Vitest files
  with 2,147 tests, all 12 hosted-C payload checks, the production Bedrock pack,

- Chrome loaded the live Web Terminal modules, rendered the connection boundary,
