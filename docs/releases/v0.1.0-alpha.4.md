# Computer System v0.1.0-alpha.4

This fourth public alpha completes the bounded CS C/C++ 2.0 and CS ABI 1.0
roadmap, expands the Computer System Python 3.14 profile, and adds a broader
guest-owned CS-Linux application environment.

This remains a prerelease. Back up a stopped world before testing it; persisted
data compatibility is not guaranteed between development alphas.

## Highlights

- Completed the bounded CS C/C++ 2.0 frontend, data models, object/linker ABI,
  static archives, deterministic floating point, hosted libc/POSIX surface, and
  `libcs-curses`.
- Added a versioned `cs-byte8-v1` data model alongside the legacy word model,
  with explicit cross-model rejection and matching guest libraries.
- Added foreground CS ABI startup, arguments/environment, streams, heap,
  credentialed filesystem I/O, waits, terminal frames, and exactly-once process
  finalization.
- Expanded Computer System Python toward the documented Python 3.14 CS Profile,
  including bounded assignments, comprehensions, classes, descriptors,
  iterators, generators, context managers, annotations, generics, typing,
  coroutines, async generators, exception groups, template strings, C3
  inheritance, `super`, and `__new__` construction.
- Added CS-Linux SysV init/crontab, guest `sed`/`awk`, archive utilities,
  process-control utilities, the v2 physical-memory manager, and bounded local
  CS System Git repositories.
- Added deterministic CSBIOS Revision 1.1 boot staging and strengthened
  scheduler, persistence, RAM, block-I/O, and terminal ownership.
- Refined Web Terminal completion, exact-session lifecycle, virtual lock
  indicators, hosted `cs-abi` frame handling, and bounded TUI input.
- Added an opt-in, isolated MCP acceptance fixture without weakening production
  login or secret-input rejection.

## C/C++ and hosted applications

CS C/C++ now carries validated function signatures, caller cleanup, one- and
two-word returns, pointers and function pointers, arrays, structs, unions,
bit-fields, globals, linkage, variadic calls, and deterministic binary32/
binary64 arithmetic. Current objects, executables, archives, debugger views,
Make fingerprints, and rootfs libraries retain their declared data model.

CS-Linux ships bounded model-matched `libc.csa` and `libcurses.csa` archives.
Guest `cc`, `c++`, `ld`, `ar`, `ranlib`, and Make select only demanded archive
members. Hosted programs receive bounded startup, standard streams, heap,
filesystem, time, directory, signal, and fixed 80x25 terminal services without
invoking a host compiler, libc, filesystem, process, or native executable.

## Computer System Python 3.14 profile

The Python frontend and runtime remain one validated CS process rather than a
separate host or guest Python VM. The expanded subset adds bounded modern syntax
and runtime protocols while sharing the same call-depth, instruction,
managed-heap, event, and process limits. The generated compatibility matrix and
manual distinguish implemented behavior from deliberate exclusions.

This release does not claim CPython ABI compatibility, arbitrary package
installation, host imports, `pip`, `venv`, native extensions, threads, or
unbounded reflection.

## CS-Linux and Web Terminal

CS-Linux now includes a bounded init/service model, the single `/etc/crontab`
surface, guest text and archive utilities, observable `nice`/`nohup`/`watch`
behavior, and local Git-like repositories with transactional object/index/ref
updates. Remote repository transport remains unavailable until an authenticated
guest networking owner is implemented.

The Web Terminal keeps exact writer/viewer ownership and fixed-cell rendering.
Completion results are bounded and typed, stale responses do not mutate input,
and hosted C terminal frames remain connected through key input and prompt
return. The isolated MCP fixture is acceptance-only and is compiled out of
ordinary production builds.

## Install

1. Back up the stopped target world.
2. Download and open `computer-system-0.1.0-alpha.4.mcaddon`.
3. Activate the imported Computer System Behavior Pack; its dependency activates
   the matching Resource Pack.
4. Use Minecraft Bedrock Edition 1.26.30 or later in the 1.26 release line.

The release ships Resource Pack 0.1.16 and Behavior Pack 0.1.7. Separate
Behavior and Resource `.mcpack` files and `SHA256SUMS.txt` are provided for
independent verification and import.

Live Web Terminal features require the source release and the local companion;
GitHub Pages remains documentation only.

## Alpha boundaries

- This is not the Phase 6 hardened release and is not long-duration multiplayer
  acceptance.
- Persisted world/data compatibility is not guaranteed between development
  alphas.
- CS C/C++ is a bounded Computer System profile, not native x86, ELF, OMF, ISO
  C++ standard-library, dynamic-linker, or unrestricted POSIX compatibility.
- Computer System Python is a bounded Python 3.14-oriented profile, not CPython
  or a host-Python bridge.
- Guest networking, package management, dynamic loading, unrestricted
  processes/threads/sockets, and CS Windows remain future work.
- The preserved reduced NetHack prototype remains frozen and is not release
  completion evidence.
