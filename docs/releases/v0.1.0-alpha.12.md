# Computer System v0.1.0-alpha.12

This twelfth public alpha completes the classic Unix scripting layer in
CS-Linux. The guest already had `awk`, `sed`, and a Python 3.14 profile but no
`perl`; it now has a bounded one, written against a modern Perl 5.40 surface
rather than a retro perl4 dialect. The release also carries the fix for a
pre-existing defect that could silently truncate hosted CS-Linux stdout inside a
tick.

This remains a prerelease. Back up a stopped world before testing it; persisted
data compatibility is not guaranteed between development alphas.

## Highlights

- Added `perl` to CS-Linux as a bounded guest shell applet (Issue #119). It
  targets `use strict`, `use warnings`, `use v5.40`, and `say`, the same way the
  repository already targets Python 3.14 on retro hardware. One-liners,
  pipelines, and script files all work from the ordinary guest shell:
  `printf 'a 1\nb 2\n' | perl -lane 'print "$F[0]:$F[1]"'`.
- Shipped a guest-owned backtracking matcher rather than reaching for the host's
  regular-expression engine. Alternation, groups and captures, greedy and
  non-greedy quantifiers, character classes, escapes, anchors, `\b`, and the
  `g`/`i`/`m`/`s` flags all run under fixed node, capture, pattern-length,
  repetition, and step budgets, so no guest-controlled pattern ever reaches a
  host `RegExp`.
- Implemented the language surface a real script actually uses: scalar, list,
  and aggregate context, `my` scoping, subroutines and recursion, `@_`, capture
  variables, `$_`, `$.`, `$0`, `$@`, `$!`, `%ENV`, `@ARGV`, statement modifiers,
  `foreach` aliasing, `sort`/`grep`/`map` blocks, `sprintf`/`printf`, `split`,
  `join`, `tr///cdrs`, `m//`, `s///` including the `e` and `r` modifiers,
  here-documents in all four forms, loop labels with `next LABEL`/`last LABEL`,
  `eval BLOCK`, `die`/`warn`/`exit`, and bounded three-argument `open`.
- Kept the applet inside the sandbox. `open` reaches only the credentialed guest
  filesystem, so DAC applies exactly as it does to every other command and no
  host path can appear in a guest-visible error. Switches are `-e`, `-n`, `-p`,
  `-l`, `-a`, `-F`, `-c`, `-w`/`-W`, `-v`/`--version`, `--`, and a script path
  with its own `@ARGV`.
- Kept a run deterministic. Hash iteration is insertion-ordered rather than
  randomized, and `time()` fails explicitly instead of leaking host wall-clock
  time into a guest program.
- Fixed hosted CS-Linux stdout truncation (Issue #118). `CsAbiRuntime.write`
  treated a transient host admission deferral on the `terminal` lane as a
  permanent error, answering the guest with `EAGAIN` and discarding text the
  guest had already handed over. It now suspends the write and resumes it, which
  is what the same runtime already did one screen further down.

## Measured fidelity

The perl work is the first in this project to be scored against its real
counterpart rather than described. A differential harness bundled the
interpreter and ran the same programs through both it and host perl 5.38.2,
comparing exact stdout and exit status across four waves totalling 373 programs.

| Wave | Focus                                                  | Scored  |
| ---- | ------------------------------------------------------ | ------- |
| 1    | core language, switches, I/O, rejections               | 140/140 |
| 2    | context, numeric edge cases, regex, sort, sprintf      | 92/93   |
| 3    | idiomatic modern Perl a script would actually use      | 86/86   |
| 4    | the features added while closing wave 3, and their mix | 48/48   |

That is 366/367, or 99.7 percent. Programs exercising a declared rejection are
excluded from the score and asserted separately.

Every defect the harness found is fixed in this release and has a regression
case: `split` with a negative limit, `chomp`/`chop` return values, four-argument
and lvalue `substr`, `^` under `/m` after a trailing newline, the `tr///`
`c`/`d`/`r`/`s` modifiers, 64-bit bitwise results, slice assignment and `$#a`
resizing, `$&`/`` $` ``/`$'`, a bare `while (<FH>)` reading into `$_`, a real
`undef` distinct from the empty string, `hex` with a `0x` prefix, `x=`,
`shift // default`, `quotemeta`, loop labels, `s///e`, and here-documents.

## Alpha boundaries

- This is a bounded Computer System profile, not a port of upstream perl and not
  a POSIX or CPAN conformance claim.
- The one scored mismatch is deliberate. There is no IV/NV duality, so every
  number is a double and an integer above 2^53 loses the exact decimal form
  upstream perl keeps: `print 9007199254740993` yields `9.00719925474099e+15`.
- Insertion-ordered hash iteration is a determinism decision, so a program that
  depends on upstream's randomized order behaves differently here.
- `do BLOCK while` and `%+` named captures are unimplemented rather than
  approximated. Lookaround, named, and modifier groups fail in the matcher.
- Rejected at compile time rather than approximated: modules outside the pragma
  allowlist, references and nested data structures, `bless` and `->`,
  `eval STRING`, POD, backticks, prototypes, package variables, `local`, `our`,
  `goto`, `format`, `tie`, `wantarray`, `fork`, `exec`, `system`, `qx`, `chdir`,
  and `qr`. A label is accepted only on `while`, `until`, `for`, and `foreach`.
- Everything stays bounded: 1,000,000 execution steps, 1 MiB of stdin and of
  stdout, 65,536 array elements, 65,536 hash entries, 262,144 scalar characters,
  8 open handles, and call depth 64. Output is admitted before it is appended,
  so a rejected write leaves the stream exactly at its bound.
- Issue #16's multi-user load evidence still does not exist. Sequential success
  is not multi-user capacity proof.
- This is not the project's Phase 6 release-hardening milestone, and it is not
  long-duration multiplayer acceptance.
- Guest networking, package management, dynamic loading, unrestricted
  processes/threads/sockets, and CS Windows remain future work.
- The preserved reduced NetHack prototype remains excluded from release
  completion percentages.

## Packaging

`/usr/bin/perl` ships at 81,920 bytes in the new `cs-linux-1.0-rootfs-v20` base
image. `cs-linux-1.0-rootfs-v19` is retained as the historical image without it
and is accepted as a non-migrating previous image, so an existing Computer keeps
its overlay and a deleted `/usr/bin/perl` keeps its tombstone.

The Behavior Pack moves to 0.1.16 because its generated script bundle changed.
The Resource Pack stays at 0.1.18 because no shipped artwork or JSON UI changed.

## Verification

- `npm run validate` passed formatting, ESLint, TypeScript, 312 Vitest files
  with 2,639 tests, the production Bedrock pack build, and the 16-chapter Pages
  build.
- `npm test -- tests/os/linuxPerl.test.ts` covers 39 cases, including the
  differential-fidelity regressions, the guest-filesystem boundary, every
  declared rejection, each capacity limit, shell one-liners and pipelines, and
  the 127 exit after `/usr/bin/perl` is deleted.
- The exact `Verify:` and `Expect:` steps are recorded in
  `docs/issues/issue-119-linux-perl.md` and
  `docs/issues/issue-118-deferred-terminal-write.md`.
- Real-Bedrock evidence for this release covers the packaged build only. The
  interpreter itself is host-verified; its in-world behavior rests on the same
  shell applet path `awk` and `sed` already use.
